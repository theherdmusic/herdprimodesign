# Herdprimodesign

Build a clickable mobile app design mockup (phone-sized, dark theme) for "Herd", a TikTok-style music video app for independent artists. Design only, with sample data.

Screens:

1. Home feed: full-screen vertical music videos, swipe up for next. Right side: heart button with count, artist avatar and follow button, share. Bottom: artist name, song title, genre tag.

2. Charts: Top 25 list updated hourly, with genre tabs (Rock, Country, Rap, Pop, more). Each row: rank, thumbnail, artist, song, heart count.

3. Live Radio: now-playing card with album art, play/pause, show name, up-next list.

4. Artist profile: avatar, bio, follower count, grid of videos, follow button.

5. Upload: pick a video, add title and genre, progress bar (3 minute limit).

6. Bottom tab bar: Feed, Charts, Radio, Upload, Profile.

Style: bold, modern, music-first, big video, minimal text, one bright accent color, rounded cards, smooth transitions. Use placeholder images where I will add my own artwork later.
